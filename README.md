# Academic homepage — white/navy, About + Research

## Preview
Open this folder in VS Code and use Microsoft Live Preview on `index.html`.

## Edit
- `site-data.js`: English/Chinese name, affiliation, biography **as an array of paragraphs**, photo path, links, papers.
- `styles.css`: appearance, desktop and mobile layout.
- `index.html`: page structure.
- `main.js`: renders content automatically. No duplicated biography in HTML.

## Photo
Put a portrait at `assets/profile.jpg` (recommended 4:5). Until it exists, the photo region hides automatically.

## Publish
Upload the **contents** of this folder to the root of your GitHub Pages repository. Keep filenames unchanged.

The two paper entries are **placeholders**, not real publications. Replace them before publishing.
